## 2. 解题总纲

把科研绘图做成可编辑、可渲染、可复核的图形生产：SVG 源文件 + PNG/PDF 预览 + 图形说明。

**本题突破方向（题面原文）：**
- 生物实体与命名规范： 处理基因与蛋白的书写区分、物种前缀、同义名与旧名、复合物与家族成员、实体 ID 与来源标注，避免同名异义和异名同义造成的错画。
- 相互作用与调控语义： 把输入文字里的“促进、抑制、磷酸化、泛素化、结合、募集、转运”等关系映射为可区分的箭头类型与端点样式，并标注证据强度或不确定性。
- 通路方向与拓扑布局： 明确上下游顺序、受体—胞内—核内的层级、跨膜与区室位置、分支与反馈环的走向，使布局本身传达正确的机制结构。
- 图例与数据编码： 处理颜色、线宽、节点大小与分组形状到表达量、显著性、置信度、时间点的映射，保证图例、图面与数据三者一致。
- 可编辑源文件与导出： 生成分层、命名清晰、字体可替换的源文件（如 SVG、draw.io、矢量绘图工程），并保证 PDF、PNG、SVG 等导出格式在分辨率、字体和图层上可用。

## 3. 单案例 SOP

1. 读取原始材料、数据字典、图形类型/尺寸/配色/字体与科学关系约束。
2. 选择 bar/line/flowchart/pathway/apparatus/graphical-abstract 模板，生成可编辑 SVG。
3. 用真实数据填图，核对坐标轴、单位、图例、误差表示与样本量；机制图核对节点/边方向。
4. 渲染 PNG/PDF 预览（环境支持时），保存 graphics_source.json 与 SVG。
5. 输出 result.json 与图形说明；科学关系不确定时标注候选/未知，不伪造通路。
