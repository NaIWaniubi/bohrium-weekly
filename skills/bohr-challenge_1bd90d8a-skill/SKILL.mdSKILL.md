## 2. 解题总纲

把科研绘图做成可编辑、可渲染、可复核的图形生产：SVG 源文件 + PNG/PDF 预览 + 图形说明。

**本题突破方向（题面原文）：**
- 数据图表生成： 从表格、统计结果或实验记录出发，按图型要求生成柱状图、折线图、散点图、箱线图、热图或多面板组合图，保证数据到图元的映射可解释。
- 样式调整： 按目标期刊、模板或团队规范调整字号、线宽、配色、图例位置、面板布局与留白，形成可复用的样式配置而非一次性手工调整。
- 标注校验： 检查轴标签与单位、刻度范围、图例与系列对应、误差线与显著性标注含义、样本量与图注一致性，识别缺失、错配与遮挡。
- 源数据关联： 建立图元与源数据字段、行号的对应关系，支持从图回溯到数据、从数据定位到图元，便于复核与返修。
- 可编辑源文件与导出： 输出符合投稿要求的可编辑矢量文件或演示文稿，控制分辨率、色彩空间、字体嵌入与透明背景等导出参数。

## 3. 单案例 SOP

1. 读取原始材料、数据字典、图形类型/尺寸/配色/字体与科学关系约束。
2. 选择 bar/line/flowchart/pathway/apparatus/graphical-abstract 模板，生成可编辑 SVG。
3. 用真实数据填图，核对坐标轴、单位、图例、误差表示与样本量；机制图核对节点/边方向。
4. 渲染 PNG/PDF 预览（环境支持时），保存 graphics_source.json 与 SVG。
5. 输出 result.json 与图形说明；科学关系不确定时标注候选/未知，不伪造通路。
