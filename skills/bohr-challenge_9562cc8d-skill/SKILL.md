## 2. 解题总纲

把学术文献检索做成可审计管线：问题拆解、跨库/跨语言扩展、去重、排序、证据回链与空结果诚实报告。

**本题突破方向（题面原文）：**
- 图表选择： 根据数据类型（连续、分类、时间序列、多变量、分组比较）和分析目的（分布、比较、相关、趋势、构成）给出可选图型与推荐理由，并说明不推荐某些图型的原因。
- 编码方式： 决定位置、长度、角度、面积、颜色、形状与分面的映射关系，处理类别过多、量纲差异大、双轴组合、对数变换等情形，避免用面积或角度夸大差异。
- 标注与图注： 生成坐标轴标目、单位、图例、误差线定义、显著性标记、样本量与统计方法说明，保证图注能独立于正文被读懂。
- 可读性： 控制字号、留白、网格线、色盲友好与灰度可辨配色、面板编号与顺序，保证缩放到单栏宽度后仍可读。
- 发表级导出： 按目标期刊或报告要求输出矢量格式或 300 dpi 以上位图，处理字体嵌入、中文与特殊符号、画布尺寸与栏宽匹配、线宽与最小字号下限。

## 3. 单案例 SOP

1. 读取 case.json/task.md，拆出研究问题、时间/语言/类型/来源约束与必需元数据字段。
2. 用 scan_index 建库；用 search_enhance 抽取 NL 硬约束并生成去废词查询计划。
3. 多路检索 + BM25/dense/RRF + PRF；用 canonical 版本去重，避免把副本当独立证据。
4. 逐条阅读 evidence/hits 全文，选章节/句子级证据并核对 sha/pages/offset。
5. 用 search_quality 生成带 [E#] 的直接答案与覆盖报告；无证据保持空结果。
