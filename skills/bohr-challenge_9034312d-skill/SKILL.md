## 2. 解题总纲

把科研绘图做成可编辑、可渲染、可复核的图形生产：SVG 源文件 + PNG/PDF 预览 + 图形说明。

**本题突破方向（题面原文）：**
- 装置结构表达： 从装置清单、装配说明或论文方法段落中抽取部件与接口，画出单元装置的结构与装配关系，处理同类部件区分、接口对齐和局部放大。
- 步骤顺序表达： 把工艺描述转成带编号的流程图，明确主序列、并行支路、循环回流与终止条件，保证编号与正文可逐条对照。
- 材料流向表达： 用箭头、线型和颜色表达物料、能量与信息的流向，处理分流合流、回流与废料出口，避免方向相反或断头箭头。
- 技术路线表达： 把研究内容划分为阶段与里程碑，画出阶段目标、方法手段、输入输出与相互依赖，使读者能看出推进顺序而非并列罗列。
- 可编辑性与导出规范： 保证图层、文字、图例、配色可修改，字体嵌入、矢量导出、分辨率与画布尺寸符合常见投稿与汇报要求。

## 3. 单案例 SOP

1. 读取原始材料、数据字典、图形类型/尺寸/配色/字体与科学关系约束。
2. 选择 bar/line/flowchart/pathway/apparatus/graphical-abstract 模板，生成可编辑 SVG。
3. 用真实数据填图，核对坐标轴、单位、图例、误差表示与样本量；机制图核对节点/边方向。
4. 渲染 PNG/PDF 预览（环境支持时），保存 graphics_source.json 与 SVG。
5. 输出 result.json 与图形说明；科学关系不确定时标注候选/未知，不伪造通路。
