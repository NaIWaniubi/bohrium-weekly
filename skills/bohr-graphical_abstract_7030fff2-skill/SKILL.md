## 2. 解题总纲

把科研绘图做成可编辑、可渲染、可复核的图形生产：SVG 源文件 + PNG/PDF 预览 + 图形说明。

**本题突破方向（题面原文）：**
- 研究问题与机制的图形化抽取： 从研究描述或实验记录中识别要表达的问题、方法路线和结论，形成“面板—要点”映射，明确哪些信息必须上图、哪些只能进图注。
- 科学实体与空间关系： 处理分子、细胞、组织、材料、器件、样本等实体的层级、位置、相互作用方向和尺度关系，避免实体混淆与层级错位。
- 数据编码与图例标注： 把核心结果映射为颜色、长度、面积、亮度等视觉通道，保证图例、色阶、单位与原始数据一一对应，并照顾色觉差异与灰度打印。
- 版式与视觉层级： 在单页内安排多面板的阅读顺序、留白、字号层级和视觉焦点，使读者按“问题→方法→结果→结论”的顺序阅读而不迷路。
- 可编辑源文件与导出规范： 输出分层、命名清楚、文字可编辑的源文件，并按规定格式与分辨率导出，处理字体嵌入、画布尺寸与印刷要求。

## 3. 单案例 SOP

1. 读取原始材料、数据字典、图形类型/尺寸/配色/字体与科学关系约束。
2. 选择 bar/line/flowchart/pathway/apparatus/graphical-abstract 模板，生成可编辑 SVG。
3. 用真实数据填图，核对坐标轴、单位、图例、误差表示与样本量；机制图核对节点/边方向。
4. 渲染 PNG/PDF 预览（环境支持时），保存 graphics_source.json 与 SVG。
5. 输出 result.json 与图形说明；科学关系不确定时标注候选/未知，不伪造通路。
